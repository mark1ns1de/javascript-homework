# Домашнє завдання з JavaScript

Кожне завдання можна запустити окремо з кореневої папки репозиторію. Потрібен Node.js. Усі результати з’являються в консолі.

| Завдання | Команда запуску | Контрольний результат |
| --- | --- | --- |
| 1. Калькулятор зарплати | `node task-1-payroll/main.js` | Загальні витрати — 145030 грн |
| 2. Каталог онлайн-курсів | `node task-2-courses/main.js` | Середня ціна — 1580 грн |
| 3. Бронювання готелю | `node task-3-hotel/main.js` | Номер 1 на 3 ночі — 4500 грн. Номер 2 на 5 ночей — 10625 грн. Номер 3 недоступний. |

Щоб запустити третє завдання в браузері, відкрийте `task-3-hotel/index.html` через локальний HTTP-сервер, наприклад Live Server у VS Code. Вивід з’явиться на вкладці Console в інструментах розробника.
